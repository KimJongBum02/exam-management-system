# 작업할 때 주의할 점
- **배포판 빌드** — `.sln` 이 없어 csproj 를 직접 빌드하면 `$(SolutionDir)` 가 비고 네이티브 DLL 이 **조용히 빠진다**(빌드는 성공한다).
  항상 `-p:SolutionDir="C:\Bash\exam-management-system\ExamManager\"` 를 준다.
  `x64\Release` 의 네이티브 DLL 이 Release 인지도 확인할 것(Debug CRT 는 강의실 PC 에서 로드가 실패한다).
- **pack URI** — 두 앱이 글자 크기를 나눠 쓰게 된 뒤로 pack URI 에 어셈블리 이름을 반드시 적어야 한다
  (`pack://application:,,,/StudentUI;component/FontSizes.xaml`). 틀어지면 **빌드는 통과하는데 화면이 전부 안 열린다**
- **줄바꿈** — 작업 트리는 CRLF(autocrlf=true). `sed -i` 와 통째로 다시 쓰는 도구는 파일을 LF 로 만든다.
  고친 뒤 `git diff --numstat` 의 추가(+) 줄 수로 확인할 것 — 줄끝이 틀어지면 파일 줄 수만큼 추가로 잡힌다
- **네이티브 소스 한글** — BOM 과 `/utf-8` 이 없어 C++ 안의 한글 문자열이 조용히 깨진다. 문자 코드값 배열로 적을 것
