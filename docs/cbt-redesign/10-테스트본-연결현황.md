# 테스트본 — NewUI 로 교체하고 기능을 연결한 상태

만든 날: 2026-09-05
위치: `c:\Bash\exam-management-system-ui-fix` (원본 저장소에서 clone)
브랜치: `fix/professor-ui-0904`

팀 합의 전 개인 확인용 사본이다. 원본 저장소는 건드리지 않았다.

## 원본과 달라진 점

- `App.xaml.cs` 가 `MainWindow`(옛 화면) 대신 `NewShellWindow` 를 띄운다. `--newui` 인자는 없어졌다.
- 실행하자마자 서버를 켜지 않는다. 마법사 2단계에서 교수가 직접 연다.
- `View/NewUI/DesignData.cs`(더미 데이터)를 지웠다. 모든 화면이 실제 저장소를 본다.

기존 `View/` 24개와 `MainWindow` 는 아직 지우지 않았다. 빌드에는 남아 있지만 열리지 않는다.

## 실행

```
dotnet build ExamManager\ProfessorUI\ProfessorUI.csproj -p:SolutionDir=<이 폴더>\ExamManager\
ExamManager\ProfessorUI\bin\Debug\net10.0-windows\ProfessorUI.exe
```

`SolutionDir` 를 줘야 `x64\Debug` 의 네이티브 DLL 과 `7za.exe` 가 출력 폴더로 복사된다.
네이티브 DLL 은 원본 저장소의 빌드 산출물을 그대로 복사해 두었다.

## 기존 코드에 손댄 곳

새로 만든 것보다 기존 것을 고친 곳이 중요하므로 따로 적는다.

- `StudentItemViewModel` — `LastUpdate`(상태가 바뀐 시각), `ConnectionText`,
  정산 화면용 `CollectText` / `CleanupText` / `ShutdownText` 추가
- `AlertItem` — `IsAcknowledged`, `Note`, `StateText` 추가. 배지가 미확인만 세도록
- `ChatViewModel` — 탭과 무관한 `RecentMessages`, `UnreadCount` 추가 (알림 패널용)
- `FileDistributeViewModel` — `RedeployOneCommand` 추가 (지각생 개별 재배포)
- `ExamEndViewModel` — 승인 시 `PacketType.ShutdownPC` 를 실제로 전송
- `OXQuizModel` — 목록 표에 쓸 `AnswerText` / `StateText` 추가

## 확인한 것

- 앱 실행 → 대시보드가 실제 상태(학생 0명, 서버 닫힘, 시험 준비 전)로 뜸
- 마법사 2단계 **서버 열기** → 포트 9000 이 실제로 열림 (netstat: 0개 → 1개)
- 학생 접속 주소가 실제 LAN IP 로 표시됨
- 좌측 메뉴 잠금이 시험 단계를 따라 동작

## 확인하지 못한 것

학생용 프로그램이 붙어야 확인할 수 있는 것들이다. 화면과 명령은 연결해 두었으나
실제 왕복은 테스트하지 못했다.

- 학생 접속 → 목록에 뜨는지
- 파일 배포 진행률과 수신 완료 표시
- 부정행위 경고 수신, 채팅 왕복
- 답안 수집과 승인 후 PC 종료

파일 선택·암호화·압축은 파일 대화상자가 필요해 자동 확인에서 제외했다.

## 연결하지 않은 것

- **OX 퀴즈 출제** — 문제를 실어 보낼 패킷 형식(`QuizQuestion` payload)이 없다.
  프로토콜과 학생 쪽 작업이 함께 필요해 이번 범위에서 뺐다.
  문제 작성 · 저장 · 삭제는 정상 동작하며, 출제 버튼만 비활성이다.
- **학생쪽 시험 종료 버튼** — 학생 UI 몫이다.
