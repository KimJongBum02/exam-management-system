# 문서 1/3 — 기능명세서 (manyfast.io 초안, 2026-09-04)

프로젝트: 학교 강의실 컴퓨터 시험 흐름 자동화 프로그램 (교수용)

## 1. 프로젝트 개요
- 한 줄 정의: 교수용 시험 운영 프로그램
- 제품 목표: 교수가 강의실 시험의 준비·진행·종료 전 과정을 단계 안내와 실시간 관리 화면으로 운영하여 시험 관리 부담과 예외 대응 시간을 줄인다.
- 배경: 학교 강의실 PC 시험 운영 시 교수는 학생 접속 상태, 시험 파일 배포, 부정행위 통제, 답안 수집과 PC 종료를 개별 관리해야 함. 졸업작품으로 C++ 네이티브 DLL + C# WPF UI 구성의 무료 교수용 데스크톱 프로그램, 학생용 프로그램과 연동.
- 사용자 문제: 학생별 접속/이탈/다운로드 상태와 늦은 입실·연결 끊김 예외를 한눈에 파악·즉시 처리하기 어려움. 프로세스/네트워크 통제 + 부정행위 알림 대응 + 준비~답안수집~흔적삭제~PC종료 반복 절차 부담.
- 해결 방안: 설치 마법사 형태의 단계별 시험 준비·시작 흐름 + 시험 시작 후 실시간 관리 창(학생 상태, 파일 재배포, 허용·금지 프로세스, 네트워크 차단, 부정행위 알림, 채팅, 답안 수집 및 종료 통합 관리).
- 차별점: 강의실 학생 PC 환경 맞춤. 시험 단계 전환, 파일 암호화·배포, 프로세스·네트워크 통제, 답안 회수 후 흔적 삭제와 PC 종료까지 하나의 교수용 운영 흐름으로 연결. 복잡한 설정 대신 안내된 순서, 진행 중 예외만 관리 창에서 처리.
- 타겟 사용자: 강의실 CBT 감독 교수/조교. Windows 강의실 PC 환경. 기술 설정에 익숙하지 않아도 단계별 안내로 운영 가능해야 함.
- 사용자 시나리오: 시험 전 학생 접속 현황 확인 → 시험 파일과 허용·금지 프로세스 설정 → 마법사 단계 따라 파일 배포 → 시험 시작 → 관리 창에서 학생 상태·부정행위 알림·채팅 확인, 지각생/연결끊김 학생 재배포 → 종료 후 답안 일괄 수집 → 수집 완료 학생 흔적 삭제·PC 종료 승인 → 완료 상태 확인.
- 핵심 지표: 교수 수동 작업 시간 감소. 파일 배포·답안 수집 성공률, 부정행위 알림 확인률, 학생 PC 종료 완료율.
- 리스크: 네트워크 불안정으로 상태 동기화/파일 전송/답안 수집 실패. 프로세스·네트워크 차단 오탐. 학생 식별 정보와 답안 파일 보안·개인정보 보호.
- 카테고리: 교육 / 학습 | 사용자 역할: 교수 | 기기: Windows 교수 PC

## 2. 주요 기능 목록

### 1. 학생 접속 및 상태 현황 [높음]
학생이 학번+이름으로 학생용 프로그램 로그인 → 교수는 접속 여부와 시험 단계별 상태를 실시간 확인. 대시보드는 미접속/대기/준비/진행 중/종료 표시. 학생 PC 제어 자체는 미포함.
수용 기준:
1. 학생 로그인 시 학번·이름이 교수용 학생 목록에 표시
2. 학생별 상태가 미접속/대기/준비/진행 중/종료 중 하나로 표시
3. 접속 또는 연결 해제 상태 변화가 현황 화면에 반영

#### 1.1 실시간 학생 상태 대시보드 [높음]
근거: 시험 중 학생별 접속·이탈과 진행 상태를 한눈에 관리해야 함. 학생 계정 생성/출석 성적 처리 미포함.
성공 기준: 학생 상태 확인·예외 학생 식별 시간 감소.
- 선행조건: 교수용 프로그램이 학생용 프로그램과 연결됨
- 트리거: 교수가 시험 현황 대시보드를 연다
- 동작: 학생별 학번, 이름, 접속 여부, 시험 상태 조회
- 결과: 미접속/대기/준비/진행 중/종료 상태 확인
- 표시: 학생 목록 + 각 학생의 접속·시험 상태
- 데이터: 학번, 이름, 접속 상태, 시험 단계

##### 1.1.1 학생 접속 상태 표시
- 트리거: 학생이 로그인하거나 연결 상태가 변경
- 결과: 대시보드에 접속/미접속 상태 표시
- 표시: 학생 목록 각 행에 학번, 이름, 접속 상태

### 2. 시험 준비 및 파일 배포 [높음]
마법사형 절차에서 시험 파일 지정 → 암호화·압축 → 준비 상태 학생 PC에 일괄 배포. 전송 완료 상태 확인, 지각/재접속 학생 재배포. 시험 외 파일 관리 기능 제외.
수용 기준:
1. 시험 파일 지정 시 배포용 암호화·압축 파일 생성
2. 준비 상태 학생에게 일괄 배포 가능
3. 학생별 다운로드 완료 여부 확인 및 재배포 가능

#### 2.1 시험 파일 배포 및 재배포 [높음]
근거: 배포와 예외 학생 재배포를 시험 흐름 안에서 관리해야 함. 학생 PC 파일 열람 미포함.
성공 기준: 배포·재배포 성공률 향상.
- 선행조건: 시험 파일 지정 + 학생이 시험 준비 상태
- 트리거: 교수가 배포/재배포 실행
- 동작: 지정 파일 암호화·압축 후 대상 학생 PC로 전송
- 결과: 학생별 다운로드 완료 상태 확인
- 표시: 시험 파일 선택 영역, 배포 실행 버튼, 학생별 다운로드 상태
- 데이터: 시험 파일, 대상 학생, 전송 시각, 다운로드 상태

##### 2.1.1 시험 파일 일괄 배포
- 선행조건: 파일 지정 + 대상 학생 준비 상태
- 동작: 암호화·압축 후 일괄 전송
- 결과: 학생별 다운로드 완료 상태 보고
- 비즈니스 규칙: 준비 상태가 아닌 학생은 일괄 배포 대상에서 제외

##### 2.1.2 예외 학생 파일 재배포
- 트리거: 교수가 대상 학생 선택 후 재배포 실행
- 동작: 선택 학생에게 기존 시험 파일 재전송
- 결과: 재배포 대상 다운로드 완료 상태 확인
- 표시: 학생 목록에서 재배포 대상 선택 + 재배포 실행 제어
- 비고: 시험 파일 내용 변경은 미포함

### 3. 단계형 시험 시작 운영 [높음]
대기 → 준비 → 파일 배포 → 시험 시작 순서의 마법사형 화면. 시험 시작 시 학생 PC의 시험 폴더 압축 해제 요청 + 진행 상태 전환. 시험 시간 관리 기능은 별도 범위.
수용 기준:
1. 대기/준비/파일 배포/시험 시작 순서 절차 안내
2. 선행 단계 미완료 시 다음 단계 진행 제한
3. 시험 시작 실행 시 대상 학생의 시험 폴더 압축 해제 요청

#### 3.1 시험 시작 마법사 [높음]
근거: 복잡한 준비·시작 절차 자동화로 운영 부담 감소. 시작 후 실시간 운영은 별도 관리 창.
성공 기준: 준비~시작까지 수동 작업 시간 감소.
- 선행조건: 교수가 교수용 프로그램에 접속
- 트리거: 교수가 시험 시작 마법사 실행
- 동작: 대기/준비/파일 배포/시험 시작 단계를 순서대로 안내
- 결과: 시험 시작 실행 시 학생 PC 시험 폴더 압축 해제 요청 + 상태를 진행 중으로 전환
- 표시: 현재 단계, 단계별 안내, 완료 상태, 이전·다음·실행 제어
- 비즈니스 규칙: 선행 단계 미완료 시 다음 단계 진행 불가

##### 3.1.1 시험 시작 실행
- 선행조건: 대기/준비/파일 배포 단계 완료
- 트리거: 교수가 시험 시작 버튼 클릭
- 동작: 학생 PC에 시험 폴더 압축 해제 요청 전송
- 결과: 시험 상태 진행 중 전환 + 관리 창 오픈 가능

### 4. 시험 보안 및 부정행위 대응 [높음]
시험 전·중 허용·금지 프로세스 목록 관리 + 금지 프로세스 실행/네트워크 외부 유출 시도 알림 확인. 실제 네트워크 차단·프로세스 통제는 학생용 프로그램이 수행, 교수용은 정책 설정과 경고 대응 담당.
수용 기준:
1. 허용/금지 프로세스 목록 등록·변경·삭제 가능
2. 위반 발생 시 학생 식별 정보 포함 알림 표시
3. 시험 진행 중에도 보안 정책 목록 변경 관리 가능

#### 4.1 보안 정책과 부정행위 알림 관리 [높음]
근거: 시험 환경 통제 + 부정행위 신속 대응.
성공 기준: 부정행위 알림 확인률 향상.
- 선행조건: 시험 진행 중이거나 보안 정책 설정 단계
- 트리거: 교수가 정책 변경 또는 학생 PC에서 보안 위반 감지
- 동작: 허용·금지 목록 변경 반영 + 위반 알림 수신
- 결과: 변경된 정책과 학생별 부정행위 경고를 관리 창에서 확인
- 표시: 허용·금지 프로세스 목록 + 부정행위 알림 목록
- 데이터: 학생 식별 정보, 감지 유형, 감지 시각

##### 4.1.1 허용·금지 프로세스 정책 편집
- 트리거: 교수가 정책 목록 편집 요청
- 동작: 허용/금지 프로세스 항목 등록·변경·삭제
- 결과: 변경된 정책 목록이 시험 보안 관리에 반영
- 표시: 허용 목록과 금지 목록을 구분 표시 + 편집 제어
- 비고: 학생 PC 프로세스 강제 종료는 학생용 프로그램 범위

##### 4.1.2 부정행위 경고 확인
- 트리거: 학생 PC에서 금지 프로세스 실행 또는 네트워크 외부 유출 시도 감지
- 결과: 관리 창에 학생 식별 정보 + 감지 유형 포함 경고 표시
- 표시: 부정행위 알림 목록 + 각 알림의 감지 시각
- 데이터: 학번, 이름, 감지 유형, 감지 시각
- 비고: 제재 조치 자동화 미포함

### 5. 시험 진행 관리 및 종료 처리 [높음]
진행 중 관리 창에서 학생 상태·부정행위 알림·채팅 확인, 종료 후 답안 일괄 수집. 답안 수집 완료 학생에 한해 시험 파일 흔적 삭제 + 학생 PC 종료 승인. 채점/답안 내용 분석 미포함.
수용 기준:
1. 진행 중 관리 창에서 학생 상태, 부정행위 알림, 채팅 접근 가능
2. 종료 후 학생별 답안 수집 상태 확인 가능
3. 수집 완료 학생에 대해 흔적 삭제 및 PC 종료 승인 실행 가능

#### 5.1 시험 관리와 종료 정산 [높음]
근거: 진행 중 예외 처리 + 종료 후 회수·정리 효율화.
성공 기준: 답안 수집 성공률 + 학생 PC 종료 완료율 향상.
- 선행조건: 시험 진행 중 또는 종료 단계 진입
- 트리거: 교수가 관리 창을 열거나 시험 종료·답안 수집 실행
- 동작: 학생 상태·채팅 제공 + 답안 수집 완료 학생 정리·종료 요청
- 결과: 답안 수집, 흔적 삭제, PC 종료 완료 상태 확인
- 표시: 학생 목록, 상태, 채팅, 종료 제어, 답안 수집·정리 상태
- 비즈니스 규칙: 답안 수집 완료 학생만 흔적 삭제·PC 종료 승인 대상

##### 5.1.1 답안 수집 및 학생 PC 종료 승인
- 선행조건: 교수가 시험 종료 실행
- 동작: 학생 PC에서 암호화·압축된 답안 폴더 수집 + 완료 학생 정리·종료 요청
- 결과: 학생별 답안 수집, 흔적 삭제, PC 종료 완료 상태 확인
- 표시: 종료 화면에 학생별 답안 수집 상태와 정리·종료 상태
- 비즈니스 규칙: 답안 수집 완료 학생만 흔적 삭제·PC 종료 승인 대상
