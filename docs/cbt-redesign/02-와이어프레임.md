## 공통 셸
- 상단바: 좌측 "시험 운영" 로고 / 우측 "연결 상태 · 알림 · 프로필"
- 좌측 사이드바 "운영 메뉴": 대시보드 / 시험 준비 / 시험 관리 / 보안 정책 / 종료 및 정산 (현재 화면은 볼드)
- 각 화면 헤더 우측: "마지막 갱신 HH:MM:SS · ● 서버 연결됨" 표시

## 화면 1. 시험 운영 대시보드 (사이드바: 대시보드)

  - 부정행위 경고: 3건 / 부제 "미확인 2건 포함"
  - 답안 수집: 0 / 32 / 부제 "시험 진행 전"
- 좌: "실시간 학생 현황" — 검색(학번 또는 이름) + 상태 필터 드롭다운
  - 테이블 컬럼: 학번 / 이름 / 접속 상태 / 시험 상태 / 최근 갱신
- 우: "우선 대응 항목" 카드 리스트 (각 항목 우측 배지)
  - 미접속 학생 · 20210042 김지수 외 3명 [● 미접속]
  - 부정행위 경고 — 미확인 · 20210017 박민준 · 금지 프로세스 실행 [● 경고]
  - 부정행위 경고 — 미확인 · 20210055 이서연 · 외부 네트워크 접근 시도 [● 경고]
  - 파일 미수신 학생 · 20210098 최현우 · 재배포 필요 [● 주의]
- 우: "보안 이벤트 요약" — 금지 프로세스 실행 2건 / 외부 네트워크 유출 시도 1건 / 오늘 총 경고 3건
- 우측 하단 주 CTA: **시험 시작 마법사 시작**

## 화면 2. 시험 준비 마법사 (사이드바: 시험 준비) — 1단계 대기
- 상단 스텝퍼 4칸: 1단계 대기 / 2단계 준비 / 3단계 파일 배포 / 4단계 시험 시작
- 좌 "대기 상태 안내": 현재 단계 = 학생 접속 대기
  - "학생들이 시험 운영 프로그램에 로그인하여 접속 확인이 완료될 때까지 대기합니다."
  - "모든 학생이 접속 완료되면 다음 단계(준비)로 이동할 수 있습니다."
  - "지각생이 있을 경우 일부 학생만 접속된 상태로 다음 단계로 이동할 수 있으나, 미접속 학생은 이후 재배포를 통해 합류해야 합니다."
- 좌 "대기 조건 점검" 체크리스트: 시험 세션 활성화(완료) / 보안 정책 로드(완료) / 네트워크 연결 상태(정상) / 시험 파일 준비 여부(미확인)
- 우 "학생 접속 현황": 전체 32명 / 접속 완료 27명 / 미접속 5명
  - 테이블 컬럼: 학번 / 이름 / 접속 상태 / 접속 시각
  - 하단 안내: "미접속 학생이 있습니다. 계속 대기하거나 다음 단계로 이동할 수 있습니다."
- 우측 하단 CTA: **다음: 준비 단계로 이동**
- (2·3·4단계 화면은 이번 전달분에 없음 — 스텝퍼만 확인됨)

## 화면 3. 시험 관리 창 (사이드바: 시험 관리) ← 핵심 화면
- 헤더 우측: 마지막 갱신 14:32:05 · ● 서버 연결 중 · [새로고침] 버튼
- KPI 카드 6개: 전체 학생 32 / 접속 중 29 / 미접속 3 / 시험 진행 중 27 / 파일 미수신 2 / 보안 경고 1

- 학생 테이블 컬럼: 학번 / 이름 / 접속 상태 / 시험 상태 / 마지막 갱신 / 조치
- 하단 좌 "보안 경고" 리스트 (항목마다 [상세 확인] 버튼)

- 하단 우 "실시간 채팅": 학생 발신 메시지 목록(아바타 이니셜 + 이름 + 본문)

## 화면 5. 보안 정책 관리 (사이드바: 보안 정책)
- "현재 보안 정책 상태": 정책 적용 상태="시험 진행 중 · 정책 활성" / 허용 프로세스 5개 등록됨 / 금지 프로세스 8개 등록됨 / 미처리 경고 2건 확인 필요
  - 안내문: "시험 중 정책이 변경되면 학생 PC에 즉시 반영됩니다. 금지 프로세스 차단은 학생용 프로그램이 수행하며, 이 화면에서는 목록 편집만 가능합니다."
- 좌상 "허용 프로세스 목록 (5개)" + [항목 추가] — 컬럼: 프로세스 이름 / 실행 파일 / 등록일 / 관리
- 좌하 "금지 프로세스 목록 (8개)" + [항목 추가] — 컬럼: 프로세스 이름 / 실행 파일 / 위험 등급 / 관리
- 우상 "정책 변경 확인": 미저장 변경 사항 목록 (예: 금지 프로세스 추가 chrome.exe / 허용 프로세스 삭제 notepad.exe)
  - "변경 사항은 저장 즉시 모든 학생 PC에 반영됩니다." + [변경 사항 저장] / [되돌리기]
- 우하 "보안 경고 요약": 김민준(20210034) 14:28 금지 프로세스 실행 감지 · chrome.exe / 이서연(20210091) 14:15 외부 네트워크 유출 시도 / [전체 경고 내역 보기] 링크

## 화면 6. 시험 종료 및 답안 수집 (사이드바: 종료 및 정산)
- KPI 카드 5개: 전체 학생 32명 / 수집 완료 24명 / 미수집 6명 / 오류 2명 / 완료율 75%
- "예외 및 주의 안내" (우측 "2건 오류 · 6건 미수집")
  - ⚠ 답안 미수집 학생 6명은 흔적 삭제 및 PC 종료 승인 대상에서 제외됩니다.
  - ✕ 수집 오류 학생 2명은 답안 전송 상태를 확인한 후 재시도하십시오.
  - ⓘ 흔적 삭제 및 PC 종료는 답안 수집이 확인된 학생에 한해 승인할 수 있으며, 이 작업은 되돌릴 수 없습니다.
- "학생별 답안 수집 현황": 검색 + 수집 상태 필터
  - 컬럼: 학번 / 이름 / 접속 상태 / 수집 상태 / 수집 시각 / 비고
- "승인 조건 안내": "아래 승인 버튼은 답안 수집이 완료된 학생(24명)에 한해 시험 흔적 삭제 및 학생 PC 종료를 실행합니다. 미수집(6명) 및 오류(2명) 학생은 승인 대상에 포함되지 않습니다."
- CTA: **흔적 삭제 및 PC 종료 승인 (24명)** → 그 아래 **종료 완료 현황 보기**

## 화면 7. 종료 완료 현황 (종료 및 정산의 후속 화면)
- KPI 카드 4개: 답안 수집 완료 28/30명(완료율 93%) / 흔적 삭제 완료 26/28명(수집 완료 기준) / PC 종료 완료 25/28명(수집 완료 기준) / 미완료·오류 4명(확인 필요)
- "학생별 종료 처리 상태": 검색 + 필터 3개(답안 수집 / 흔적 삭제 / PC 종료)
  - 컬럼: 학번 / 이름 / 답안 수집 / 흔적 삭제 / PC 종료 / 비고
- "미완료 및 오류 안내"
  - 답안 미수집: 네트워크 오류 또는 학생 미제출로 인해 답안이 수집되지 않았습니다. 해당 학생의 흔적 삭제 및 PC 종료는 실행되지 않았습니다.
  - 흔적 삭제 오류: 파일 삭제 중 오류가 발생했습니다. 학생 PC에서 수동으로 확인이 필요합니다.
  - PC 종료 미실행: 종료 명령 전송에 실패했거나 응답이 없습니다. 현장에서 직접 종료를 확인하십시오.
- 완료 배너: "시험 종료 작업 완료 — 모든 처리 가능한 학생의 답안 수집, 흔적 삭제, PC 종료가 완료되었습니다. 미완료 학생은 위 안내를 참고하여 현장 조치하십시오."

## 유저플로우 다이어그램 (가로 18832px 대형 이미지)
스윔레인 4개로 구성된 플로우차트. 전달된 해상도에서는 노드 텍스트가 판독 불가.
읽어낸 것은 레인 구조와 노드 형태/개수뿐:
- 레인 1 (최상단): 검은 시작 노드 → 사각 2개 + 마름모(분기) 1개 → 레인 2로 하강
- 레인 2: 사각 → 평행사변형(입출력) → 마름모 → 사각, 우측으로 "재시도/실패" 계열 라벨
- 레인 3 (시험 준비/배포 추정): 가장 긴 체인. 사각/평행사변형/마름모 교차, 붉은 역방향 화살표 1개(레인2로 되돌아감 = 실패 시 롤백/재시도)
- 레인 4 (시험 진행 관리 추정): 중앙 허브 노드에서 4갈래 분기(위 2개 = 마름모 포함 경고 처리 경로, 아래 2개 = 채팅/재배포 추정)
- 레인 5 (최하단, 종료 및 정산 추정): 사각 → 사각 → 마름모 → 사각 3개 연쇄 → 종료
※ 텍스트 확인 필요. 원본 SVG/PNG 또는 구간별 확대 캡처가 있으면 정확히 반영 가능.
