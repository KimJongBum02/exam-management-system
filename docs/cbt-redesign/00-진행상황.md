원본 기획은 manyfast.io 에디터에 있으나 로그인이 필요해 외부에서 읽을 수 없다.
사용자가 텍스트·이미지로 전달한 것을 옮겨 적은 것이 위 문서다.

## 지금 상태 — 새 UI 가 교수 화면이다

팀 합의로 교수 UI 를 새 구조로 교체했다. `App` 이 `ShellWindow` 를 띄우며,
`--newui` 같은 별도 인자는 없다. 그냥 실행하면 새 화면이 뜬다.

기존 교수 화면은 지우지 않고 `ExamManager/ProfessorUI/View/_Legacy/` 로 옮겨 두었다.
되돌릴 수 있도록 빌드에서는 빼지 않았다 — 컴파일은 되지만 어디서도 띄우지 않는다.

```
ExamManager/ProfessorUI/View/
├── Professor/  지금 쓰는 교수 화면 (셸 · 화면 8종 · 스타일)
└── _Legacy/    옛 화면 12개 폴더 + MainWindow (쓰지 않음)
```

이름에 `New` 를 붙이지 않는다. 지금은 이것이 유일한 교수 화면이라
시간이 지나면 무엇에 비해 새 것인지 알 수 없게 되기 때문이다.
셸은 `ShellWindow`, 공용 뷰모델 모음은 `UiContext`, 스타일은 `Styles.xaml` 이다.

## 실행

```
dotnet build ExamManager\ProfessorUI\ProfessorUI.csproj -p:SolutionDir=<저장소>\ExamManager\
ExamManager\ProfessorUI\bin\Debug\net10.0-windows\ProfessorUI.exe
```

`SolutionDir` 를 줘야 `x64\Debug` 의 네이티브 DLL 과 `7za.exe` 가 출력 폴더로 복사된다.

## 화면 구성

좌측 운영 메뉴 6개. 시험 단계(`ExamState.CurrentPhase`)에 따라 잠긴다.

| 메뉴 | 화면 | 잠금 |
|---|---|---|
| 대시보드 | 운영 상태·학생 현황·우선 대응 항목 | 항상 열림 |
| 시험 준비 | 마법사 4단계 (시험 준비 → 서버 열기 → 파일 배포 → 시험 시작) | 시험 시작 전까지 |
| 시험 관리 | 학생 목록·경고·채팅·재배포·시험 종료 | 시험 시작 후 |
| 보안 정책 | 허용·금지 목록 편집, 학생 PC 에 적용 | 항상 열림 |
| 종료 및 정산 | 답안 수집·승인·종료 완료 현황 | 시험 종료 후 |
| OX 퀴즈 | 문제 작성·출제·응답 정산 | 항상 열림 |

상단바에 서버 상태와 알림 배지(미확인 경고 + 안 읽은 채팅)가 있고,
알림을 누르면 어느 화면에서든 우측 패널로 경고와 채팅을 볼 수 있다.

## 정한 것

- **한 창에 다 담는다.** 준비와 관리를 다른 프로그램으로 쪼개지 않는다.
  대신 화면은 단계별로 갈라 각 시점에 필요한 것만 보여 준다.
- **메뉴를 시험 단계로 잠근다.** 기존 `ExamState` 를 그대로 쓰고,
  잠금 지점만 버튼에서 메뉴로 한 겹 앞당겼다. 화면 안쪽 버튼 잠금은 이중 안전장치로 남는다.
- **마법사 순서는 파일·정책·서버가 학생 접속보다 앞선다.**
  1단계 시험 준비 → 2단계 서버 열기 → 3단계 파일 배포 → 4단계 시험 시작
- **표는 헤더와 값을 모두 가운데 정렬한다.** 셀이 열 너비를 받도록
  `ListViewItem.HorizontalContentAlignment` 를 Stretch 로 둬야 정렬이 먹는다.
- **OX 퀴즈 출제 조건은 시험 단계가 아니라 서버·접속이다.**
  본래 목적이 수업 중 이해도 확인이라 시험과 무관하게 쓸 수 있어야 한다.

## 아직 안 한 것

1. **서버 열기 버튼을 대시보드로** — 지금은 마법사 2단계에만 있다.
   수업 중 퀴즈만 쓰려는 경우에도 마법사를 거쳐야 해서 불편하다.
2. **`OXQuizModel` 의 과목 항목 정리** — 이름을 주제로 바꾸고 선택 입력으로,
   비어 있어도 미완성으로 보지 않게 한다.
3. **시험 로그 엑셀 출력** — 학번·이름·시험 상태·부정행위 목록.
   `.csv` / `.xlsx` 중 형식이 아직 정해지지 않았다. OX 퀴즈 누적도 함께 낼지 정해야 한다.
4. **여러 학생 동시 응답 확인** — OX 퀴즈를 한 명으로만 왕복해 봤다.
   강의실에서 30명이 동시에 누르는 상황은 실제로 붙여 봐야 안다.
5. **옛 화면 정리** — `_Legacy` 를 빌드에서 뺄지, 언제 지울지.
   같이 딸린 `MainViewModel` · `SidebarViewModel` · `NavigationStore` · `LayoutStore` 도 함께 정리 대상이다.
